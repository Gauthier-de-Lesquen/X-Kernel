X-Kernel
========

Overview
--------

X-Kernel is a huge project I launched because I'm tired of all the compatibility issues we find today. The goal is to build a kernel that is firstly Windows, MacOS and Linux compatible (executable formats, syscalls, etc.) and after, whynot 64bits and 32bits compatible and x86, ARM, Mips etc. compatible. As you will have gathered, the goal is that any executable file, no matter of the OS or the CPU architecture, will be understood by X-Kernel.

X-Kernel is Linux-Based. Know more about Linux [here](linux-README.md)
